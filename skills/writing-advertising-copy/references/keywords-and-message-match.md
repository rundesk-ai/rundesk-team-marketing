# Use keywords and query intent in ad copy

Keywords are evidence about a potential matching route, not a complete account of the person or a
license to repeat phrases. Work from supplied keyword, search-term, query-theme, or customer-language
evidence. Researching demand, volume, competition, bid estimates, and campaign structure belongs to
the evidence or media owner.

## Classify the supplied intent

For each useful query theme, record:

```text
Query or theme | likely task | awareness | required meaning | landing page | confidence / evidence
```

Distinguish navigational brand intent, category or solution seeking, problem exploration,
comparison, transaction, location, and support or informational intent. One phrase can be ambiguous;
do not resolve it toward purchase merely because an ad is being written. Split materially different
tasks into separate message sets or return the ambiguity.

## Map meaning across the path

Maintain semantic continuity:

```text
query intent -> headline recognition -> supported value/proof -> CTA -> destination fulfillment
```

Use the primary term in a headline or prominent field when it improves recognition and reads
naturally. Exact wording is optional unless the approved platform plan requires it. Synonyms and
plain-language variants can preserve intent better than awkward repetition. Supporting assets
should add benefit, proof, terms, objection handling, or action rather than echo the keyword.

Reject:

- irrelevant terms included only for volume or trend;
- a keyword whose implied product, location, price, audience, or availability the offer lacks;
- keyword stuffing, density targets, or every headline beginning the same way;
- competitor trademarks or comparisons without policy and approval review;
- informational queries sent to a purchase page that does not answer them; and
- landing pages that omit the advertised product, promotion, term, or action.

## Treat dynamic insertion as executable variation

When keyword insertion or another customizer is requested, enumerate representative, longest,
awkward, regulated, trademarked, misspelled, and adversarial substitutions. Each rendered asset must
fit the current limit, remain grammatical, preserve brand voice, match the destination, and avoid a
new or stronger claim. Supply a safe default. Do not recommend insertion when the keyword set is too
broad or heterogeneous to satisfy those checks.

## Return the mapping

For each message set, name the query theme, user task, matching headline assets, non-keyword value or
proof assets, destination, and unresolved mismatch. Do not claim a term will attract, convert, or
lower cost without observed experiment evidence. A platform score is a diagnostic for asset
relevance and variety, not proof that the offer, page, or audience will perform.
